Diagram icons

Icon support for diagrams (DGM-17). Nothing here is built; these frames are for approval before any UI code (ADR-011). Scope follows the owner’s decision of 2026-11-24: OpenCanvas ships only generic icons it is free to ship (Lucide, ISC, plus our own glyphs). No vendor or brand icons are bundled or offered as packs. Product logos (Jitsi, Nextcloud, S3 and the rest) are added by people themselves, cleaned on the server and kept in the document.

Product logos shown here are neutral placeholders: initials in a dashed tile, standing in for the file a person uploaded. All other icons are drawn properly: Lucide or our own. Colours are OpenCanvas tokens. Use the switch above for light and dark.

Decisions for the owner are marked Decision: product names as search keywords (1c) and the team-library suggestion (3c). The rest are listed in the ADR.

I1 · Icons library in the shapes panel Built in: generic only

One new library, Icons, sits under the approved libraries (DGM-14 S2) with 53 generic icons in eight groups. Every icon is either Lucide (ISC) or drawn by us in Lucide’s style; there are no vendor or product logos. Above it, In this document holds icons people added themselves. Crops at real size (256 px).

I2 · Add icon: upload, paste and cleaning Server-side sanitising

The centrepiece. Upload, drop or paste an SVG or PNG; the server cleans it and answers with exactly what it removed; the person names it and adds keywords; the cleaned copy is stored in the document. Product logos in these frames are neutral placeholders (initials in a dashed tile) standing in for the uploaded file.

I3 · Icons in this document Stored in the .ocanvas

Added icons belong to the document (ADR-001: the host owns the file). They travel with it in every export, copy and template, and everyone who can edit can reuse, rename or replace them.

I4 · An icon as a diagram shape kind icon:node, base rect

An icon shape is a registry kind (icon:node) on the rect base (ADR-045): label below or to the right, four ports on its box, connectors like any shape. Older clients and exports without icon support draw the box with its label (I6).

I5 · Team icons from the host (optional) Host callback, no admin UI

Kept small. OpenCanvas has no admin screens, so a team’s own icons come from the host, the same way team templates do (TPL-01). If the host doesn’t answer, the section simply isn’t there. No vendor or brand packs are offered by OpenCanvas.

I6 · When an icon is missing ADR-045 §5 fallback

An icon reference that can’t be resolved never loses the shape. The editor draws an empty icon frame; exports and older clients draw the base rectangle with the label.
