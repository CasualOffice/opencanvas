Decisions for the owner
  1. Recommendation: A, one bottom row with tools left and zoom right, priority overflow into “More” (2a–2c, 3a–3d). B and C are shown for comparison.
  2. Priority order (also the visual order): Select, Sticky note, Pen | Text, Rectangle, Arrow, Ellipse, Diamond, Pan. Pan overflows first (3a). Today’s order changes, so muscle memory moves for Pen and Sticky.
  3. Overflow is measured on the board’s own width (ResizeObserver), so side panels and narrow embeds behave the same as small windows (2b).
  4. Zoom pill collapses to a single “100%” button that opens zoom in, out, fit and minimap, and only after tools have overflowed down to three (2c).
  5. Offer B (vertical rail) as a personal setting “Tools on the left” inside More, not as a default (3b). Default it on in diagram full screen?
  6. Reject C (single tool button): a second tap for every tool change (2f).
  7. Touch targets: 44 px in compact layouts, 34 px on desktop (3c).
  8. Keyboard: one Tab stop per group (canvas, top actions, tools, zoom), arrows inside, Enter or ↑ on More opens the menu (3d).
  9. Acceptance for UX4-01: no overlap and every tool reachable at 1280 × 200%, 24 px root, 320 px, with and without the side panel; checked in Playwright on the board’s bounding boxes.

Board toolbar at narrow widths

The board and diagram tool bar at 200% zoom, a 24 px root and 320 px (docs/36 §6.3, UX4-01, from SCALE-02 S3). Section 1 recreates today’s layout with the board’s real CSS; sections 2 and 3 are proposals. Each frame is drawn at real size: a zoomed frame shows the CSS-pixel viewport scaled the way the browser would. Magenta labels and numbers are review notes, not UI. Icons are Lucide.

1 · Today: the problem UX4-01 · SCALE-02 S3

Recreated with the board’s real CSS (board/src/styles.ts). The tool bar is centred at the bottom and the zoom pill sits at the bottom right, independently. They collide as soon as the board is narrower than about 38 rem of content, and the tool bar then scrolls sideways behind a fade.

2 · The fix: alternatives UX4-01

Three ways to keep every tool reachable without overlap. All three put the zoom control in the same row or corner as the tools so they can never overlap, and all keep 44 px targets in compact layouts.
