Decisions for the owner
  1. One context menu for right-click, long-press (500 ms, touch) and Shift+F10 / the Menu key. A shape menu and a canvas menu, every entry with its shortcut. Order: Cut, Copy, Paste, Duplicate · Copy as PNG, Copy as SVG · Arrange ▸, Align ▸ · Group, Wrap in frame, Lock · Add link, Copy link to shape · Delete. On a phone it is a bottom sheet with four big actions on top. Nothing lives only in the menu: the floating toolbar gets a More (⋯) button that opens the same menu, and every entry is in Commands too. BRD-18 · 2a–2c
  2. Tool lock: a lock button at the end of the tools and Q (Excalidraw's key, the idea not the code). Double-clicking a tool locks it too. Default off; Pen always stays on as today. The active tool shows a small lock badge while locked; Esc or V returns to Select and unlocks. BRD-19 · 3a
  3. Tool keys stay letters (V N P T R A O D H) plus new F Frame and Q lock. No 1–0 digit aliases: our tool order differs from Excalidraw's, so the digits would not carry muscle memory over. 3b
  4. Style panel docks to the board's right edge on desktop (a sheet on phones), opened by Style in the floating toolbar or ⌥S; in diagram mode the same controls sit in the Properties panel (one component). Stroke colour and fill are separate; colours are the seven theme tones plus Ink and None, no free hex picker this round, so every board still flips cleanly between light and dark. Stroke width Thin / Medium / Bold, Solid / Dashed / Dotted, opacity 10–100 %, start and end arrowheads (None, Arrow, Triangle, Dot), font Sans / Serif / Mono (no hand-drawn font: none we can ship under our licence rules), size S / M / L / XL, rotation in degrees. New shapes use the last style you picked (per person, not stored in the board). BRD-22 · 4a–4c
  5. Rotation: a handle above the selection; it snaps to 15° while dragging and Alt turns snapping off, the same modifier that turns off alignment snapping when moving. ⇧R / ⌥⇧R rotate by 15° from the keyboard. Frames and connectors never rotate. New keys are additive (rot, stroke, sw, dash, op, font, ah); 0.1.x clients ignore them; PNG, SVG and draw.io exports draw them. BRD-22 · 11a
  6. Frames are a real tool (F): a named container stored as the existing diagram:container kind with explicit membership (props.parent, as BRD-09's auto-layout already writes), so auto-layout, export and the outline agree. A shape joins the frame its centre is dropped in; moving a frame moves its members; frames do not clip content; deleting a frame keeps its contents unless you pick "Delete frame and contents". Double-click the name to rename. Frames are listed in the zoom menu, and Present (⇧P) steps through them full screen. BRD-21 · 5a–5c
  7. Export: one dialog for PNG and SVG with Background Transparent / Light / Dark, a Colours choice when transparent, scale 1× / 2× / 3× for PNG, and scope (whole board, the selection, or one frame). Default background Light, the last choice remembered per person. Copy as PNG (⇧⌘C) and Copy as SVG are in the context menu and the dialog; where the browser cannot put an image on the clipboard, it says so and offers Download. BRD-20 · 6a
  8. Narrow diagram header: the title keeps at least 8 rem and folds things away in this order: Commands loses its label and ⌘K chip (under 64 em) → the document crumb, "Back to document" label, Outline and Auto-layout go (under 48 em; the last two into ⋯) → Commands and Redo move into ⋯ (under 36 em) → the existing two-line phone header (30 em and under). Measured on the diagram window, not the screen. BRD-17 · 7a–7b
  9. Smart guides on by default in the whiteboard too (edges and centres, pink lines, the equal-gap marks diagram mode already has); Alt while dragging moves freely; "Snap to objects" in the canvas menu turns them off per person. Grid snapping stays diagram-only. 8a
  10. Quick-connect handles on the four sides of one selected shape (not on hover of every shape, which is noisy): click adds the same kind of shape on that side, connected, and starts typing in it; drag draws a connector to another shape, or into empty space where it makes a new shape. Diagram mode keeps its ports. 8b
  11. Empty board: hints for drawing, double-click to type, the shortcut sheet, and three starter templates (Retrospective, Flowchart, Brainstorm). The hints go away with the first shape and are never shown to view-only people ("This board is empty"). 9a
  12. Together: others' cursors with name labels (the label fades after 4 s still, the arrow stays), their selections as rings in their colour with their name. Avatars appear in the board's top cluster when someone else is there; click one for Follow or Go to cursor. Following draws a frame in their colour with "Following Lea · Stop"; any pan, zoom or Esc stops it. Needs the viewport in awareness (never document data). 10a–10b
  13. Selection: marquee selects shapes fully inside; Alt while dragging the marquee selects any it touches. Shift-click adds or removes. Eight resize handles (Shift keeps proportions, Alt resizes from the centre). Several shapes resize and rotate together. Locked shapes are skipped by the marquee and show a lock badge when clicked. 11a–11b
  14. Keyboard and screen reader: everything above has a key or a menu path; Tab walks shapes in board order; every change is announced ("Rectangle rotated to 30 degrees"). Align gets ⌥⇧ + arrows; Add link is ⇧⌘K because ⌘K is Commands. 12

Whiteboard UX pass

The owner calls whiteboard UX critical. This page covers the six rows that wait for a prototype (BRD-17..22) and the UX gaps of the board audit (docs/41 §3): the context menu, tool lock, a style panel with rotation, frames, export, the narrow diagram header, the creation flow, the empty board, working together, selection and the keyboard.

Frame 1 is a working board. Right-click or long-press anything, drag shapes near each other, rotate, resize, try the lock, open Style, Export or Present. Each later section has a button that sets up its case in frame 1. Where Excalidraw (seen through opencanvas.studio) does something better we take the idea, not its assets or code. Icons are Lucide-style outlines; the colours are the product's tokens, in light and dark.

1 · The board, working all rows

The inline board block as in a document (36 rem tall), with the approved v0.4 bottom row. New: Frame in the tools, the lock, the avatars in the top cluster, the More (⋯) and Style buttons in the floating toolbar. Make the window narrow, or pick 22 em below, to see the compact layout and the sheets.

2 · Context menu BRD-18

Right-click, long-press or Shift+F10. On a shape it acts on the selection (right-clicking an unselected shape selects it first); on empty canvas it is the canvas menu. Submenus open on hover, → or Enter; ← closes them. Disabled entries stay in the list with the reason in the tooltip, so the menu keeps its shape.

Excalidraw showed the full list with shortcuts and "Wrap selection in frame"; we keep that, drop "Copy styles / Paste styles" for now (the Style panel's last-used style covers most of it), and add Copy link to shape, which links into the document at this shape. Flip horizontal and vertical wait for rotation to land.

3 · Tool lock and the keyboard map BRD-19

Today every placement returns to Select. With the lock on, the tool stays until Esc or V. The lock sits after the tools so it is never the first thing to overflow; at narrow widths the hidden tools go into More but the lock stays.

4 · Style panel and rotation BRD-22

Only the sections that apply to the selection are shown; several shapes with different values show no pressed value and "Mixed". Every control writes one key per shape, so two people changing different properties both keep theirs (ADR-045). Opacity applies while dragging the slider and is one Undo step.

5 · Frames BRD-21

A frame is a named area that owns the shapes in it. It is drawn under everything else, with its name above the top-left corner at a constant screen size. Drawing a frame around existing shapes adopts them; "Wrap in frame" (⇧F) puts one around the selection. Dropping a shape adds it to the frame under its centre and says so ("Added to Next sprint").

6 · Export and copy as image BRD-20

Today export is light only and there is no copy to the clipboard (D15). The dialog below is live and draws the board from frame 1. Background and colours are separate choices: a transparent PNG for a dark slide needs light strokes, so "Colours" appears when the background is transparent.

7 · The diagram header at narrow widths BRD-17 · D11

At 500 px today the title shows "H." while Commands keeps its ⌘K chip. The header now gives way in a fixed order so the board's name always has at least 8 rem. Drag the slider to see each step; the ⋯ menu lists what it holds at that width.

8 · Creating shapes docs/41 §3

Drag to size is built (BRD-07). New: smart guides and snapping on the whiteboard, quick-connect handles, and a size readout while drawing. Double-click empty canvas to type stays; double-click a shape edits its text; double-click a frame's name renames it.

9 · The empty board docs/41 §3

Today: a shapes icon, "Pick a tool below, or double-click to add text" and one key hint. The new state teaches the three things people look for, offers starter templates, and points at the tools.

10 · Working together docs/41 §3

Cursors, selections and the viewport are awareness, never document data. A person's colour is the same in the avatar, cursor and ring. When following, your own edits still work; panning or zooming stops following, as does Esc.

11 · Selection, handles and rotation BRD-22

One shape: an accent outline, eight handles, the rotation handle and the four quick-connect handles. Several: one dashed box around all with corner handles and the rotation handle, each shape outlined. Handles are 0.5 rem on desktop and get a 2.75 rem touch area on touch screens.

12 · Keyboard and screen reader

The board is one Tab stop (role application, with the instructions in its label); inside it Tab and Shift+Tab walk the shapes in board order and the floating toolbar, Style panel and menus are reachable with the keys in 3b.
