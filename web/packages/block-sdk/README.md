# @opencanvas/block-sdk

Write OpenCanvas blocks: `defineBlock`, the typed `BlockContext` of the sandbox bridge,
`defineMigrations` for script migrations, a DOM helper `h`, and a test harness
(`@opencanvas/block-sdk/harness`).

The guide is [docs/32-BLOCK-SDK.md](../../../docs/32-BLOCK-SDK.md). The samples in `samples/` build
with `node scripts/build-samples.mjs` (`--check` verifies the committed packages).
