Benchmarks

Benchmark results for OpenCanvas with the hardware, store and load mix of every run: edit latency, memory and reconnect times per scenario.

Every number below comes from a result file in bench/results/, produced by scripts/bench/run (docs/36 §3). Each result names the machine it ran on, the hardware, the store and the load mix. **Results marked local ran on a developer laptop in short form, not on the reference machine (4 vCPU, 8 GB), and are not the published capacity.** The capacity page has the sizing guidance.
