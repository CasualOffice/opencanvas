Glossary

Terms used across the OpenCanvas documentation: host, canvas, block, room, owner node, launch token, session ticket, WAL, CRDT and WOPI.

TermMeaning
HostThe integrating application. Owns users, ACL, files, versions.
CanvasOne collaborative document: blocks + boards + comments.
BlockA unit of content with a stable id (paragraph, table, image, board…).
BoardA whiteboard surface embedded as a block.
RoomThe live, in-memory collaboration session for one (host, file).
Owner nodeThe single cluster node holding a room's authoritative Doc.
Launch tokenHost-signed JWT stating file, user, role, perms.
Session ticketShort-lived, single-room credential for the WebSocket.
GrantVerified result of a launch: {host, file, user, role, perms, exp}.
CommitSerialising the room to .ocanvas and saving it to the host (autosave or manual with message).
WALroom_updates + room_snapshots: transient log so no acked edit is lost before commit.
AwarenessEphemeral presence state (cursor, pointer, name, colour).
**.ocanvas**Native zip file format (manifest, document.json, ydoc.bin).
WOPIWeb Application Open Platform Interface — the Collabora/Office host protocol.
CRDTConflict-free replicated data type (Yjs here).
UnfurlFetching a link's title/description/image to render a link card.

Generated from docs/12-GLOSSARY.md in the repository; edit it there. Last changed 2026-11-21.
