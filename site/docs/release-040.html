Release notes 0.4.0

OpenCanvas 0.4.0 release notes: spreadsheets, advanced databases, Timeline, charts, partial sync, performance, upgrade notes and limitations.

Status: released 2026-11-28, tag v0.4.0. Licence: Apache-2.0 (ADR-037). Plan: docs/36. Approved prototypes: docs/prototypes/v04-approved/. Benchmarks: site benchmarks page; results are in bench/results/ and e2e/perf/results/.

OpenCanvas 0.4.0 adds spreadsheets, advanced databases and charts, and is a performance and reliability release. The host still owns users, permissions and files; the server never stores documents (ADR-001). Support is best effort, with no SLA.

1. What 0.4.0 contains

Spreadsheet block (SHEET-00..08)Excel-style grid on opencalc's engine with our own grid: name box, formula bar, Excel keyboard, about 120 functions per cell, sheets, fill and Ctrl-drag, paste from Excel and Sheets with options, formats, freeze, filters, merge, borders, wrap, find and replace, move/hide rows and columns, tab colours; full screen; live editing with peers' selections; phone layout and view only; offline. .xlsx/.ods import (with formats, styles and widths) and .xlsx export; values in exports, search.json, the API and MCPADR-080

2. Upgrade notes (from 0.3.x)

  1. Partial sync is on by default. Editors before 0.4 are closed with 4426 on split rooms. Deploy the 0.4 editor with the 0.4 server, or set [host.flags] partial_sync = false.
  2. Migrations 0012 (WAL per document id) and 0013 (restore epoch) run at start-up.
  3. HS256 hosts need a non-empty secret (jsonwebtoken 12 refuses an empty one).
  4. **Busy servers answer 503 with Retry-After.** Clients should retry after the given delay; the editor and SDKs already do.
  5. New block types core.spreadsheet and core.chart; xlsx and ods in import_formats and export_formats when the host allows them.
  6. Container: ghcr.io/casualoffice/opencanvas:0.4.0. Helm chart 0.4.0.

3. Known limitations (v0.4.1)

  • Partial sync does not split spreadsheets yet; open partial-sync items are PSYNC-BUG-1..4. The 50 MB first screen is above the 2 s target.
  • Spreadsheet: cell comments, the "changed since" undo message, merge and wrap in the phone layout, merges across frozen panes.
  • Charts: no browser test yet for database charts and the live database ⇄ spreadsheet view; the chart is placed after the sheet, not floating over it.
  • Timeline: Workload reassigns through a select, not by dragging; no Months grouping on phones; Timeline is not in the insert menu.
  • The slow-host save drill now passes on SQLite and MySQL 8.4; SBOMs and the update policy (DEP-01) are in place since 2026-11-28 (for v0.4.1).
  • Benchmarks marked local ran on a developer laptop, not the reference machine.

4. Release checklist

  1. Pre-push gates, cargo test for oc-server, oc-model and oc-sheet, and the full Playwright suite on the release commit (157 of 159 passed in one run; the import-dialog wording test was updated and passes, and the access-expiry test passed alone).
  2. CI green on main.
  3. Version 0.4.0 everywhere, CHANGELOG dated.
  4. gh release create v0.4.0 --target <sha>.
  5. Check the binaries and the container on the release.
