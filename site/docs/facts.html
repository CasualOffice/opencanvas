Facts

OpenCanvas in short, for people and for tools that quote it. Each row links to the repository file, test or tracker entry it comes from; the release and its date are read from Cargo.toml and CHANGELOG.md when the site is built.

What is OpenCanvas?

OpenCanvas is an open-source, real-time collaborative canvas that other applications embed. One document holds rich text, databases and whiteboards, with live cursors and comments. The host application keeps the users, the permissions and the file; OpenCanvas does the editing, merges every change live and saves the file back to the host. Source: README.md, “An embeddable, real-time collaborative canvas for your app.”
