Release notes 0.1.2

OpenCanvas 0.1.2 release and upgrade notes for host integrations, diagramming, version history, and the headless API.

OpenCanvas 0.1.2 adds host integrations, structured diagramming, version history, and a versioned headless API. See the changelog for changes since v0.1.1 and the execution tracker for implementation and test evidence.

What's included

  • The Nextcloud app uses WOPI and keeps canvas files, versions, and shares in Nextcloud. The Mattermost plugin adds canvases to channels. The Element / Matrix widget provides shared room canvases. Jitsi Meet continues to support temporary meeting canvases.
  • Diagram mode adds libraries, ports, routing, and auto-layout. Import draw.io and Excalidraw with a dry-run report, and export draw.io and Mermaid alongside PNG and SVG. See the diagram guide for format coverage and mixed-version behavior.
  • Version history supports named saves, comparison, restore, and a 30-second undo after restore. The history menu depends on host capabilities and user permissions.
  • The host integration guide describes the headless API, scoped access, and host launch options. Read the operations guide for deployment and monitoring.

Upgrade notes

  • Back up host files and follow the recovery guidance before upgrading. Allow active saves to complete before replacing the server.
  • Use ghcr.io/casualoffice/opencanvas:0.1.2 for the container. For Helm, use chart 0.1.2 from the checkout with image.repository=ghcr.io/casualoffice/opencanvas. WOPI hosts still need proof keys. Consult the v0.1.0 upgrade notes for older deployments.
  • Configure each integration with its own guide, including the allowed iframe origins. Hosts adopting version history should check their callback support and the permissions granted to each user.

Known limitations

Support is best-effort, with no production SLA. Start with a single node and review the capacity guidance before scaling. AI and MCP are experimental and off by default. For diagram interchange and mixed-version sessions, see the diagram guide.
