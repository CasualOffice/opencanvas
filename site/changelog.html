Release 0.1.0-alpha.1

Embeddable collaborative workspace canvas. The first alpha, for evaluation, with no production SLA: rich text, databases, whiteboards, templates and collaboration; a standalone SQLite deployment and the host SDK; import and export for the tested formats. The AI assistant and MCP endpoint are experimental and off by default. Read the release notes for the acceptance evidence, the known limitations, and backup and recovery; the summary is in CHANGELOG.md.
