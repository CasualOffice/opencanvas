Changelog

What was merged and verified, newest first, from the integration log in the project's tracker. Each entry says what changed and how it was checked.

Release 0.2.1

Released 2026-11-26. A new insert menu: Quick insert, Recent, goals like "track tasks", and five categories, with heading, list, callout, column, database-view and diagram-type variants in one place. Shortcuts like /h2 still work. See CHANGELOG.md.

Release 0.2.0

Released 2026-11-25. Stable headless API under /api/v1, on by default, with TypeScript and Rust clients; signed webhooks; the block SDK for your own blocks; and host editor profiles. See the release and upgrade notes.

Release 0.1.2

Nextcloud, Mattermost, and Element / Matrix integrations, plus diagram mode, version history, and the headless API. See the release and upgrade notes.

Release 0.1.1

Jitsi Meet integration and temporary canvases. One Prosody plugin and config give every Jitsi meeting a shared canvas under Shared document, like Etherpad, with no Docker changes; tested against a stock docker-jitsi-meet with two browsers. Hosts without file storage can set storage = "ephemeral": canvases start blank or from a built-in template, survive a server restart, and are deleted when the meeting ends. Also: the block handle no longer disappears before you reach it, and the template button inside an open canvas is gone. See Jitsi Meet and CHANGELOG.md.

Release 0.1.0

The first release: 0.1.0-alpha.1 plus the SEC-33, SEC-34 and SEC-35 security fixes, WOPI proof keys, block schema validation and the template load test, with best-effort support and no SLA. WOPI hosts now need proof keys and MCP needs a public URL: read the upgrade notes before upgrading.

Release 0.1.0-alpha.1

Embeddable collaborative workspace canvas. The first alpha, for evaluation, with no production SLA: rich text, databases, whiteboards, templates and collaboration; a standalone SQLite deployment and the host SDK; import and export for the tested formats. The AI assistant and MCP endpoint are experimental and off by default. Read the alpha release notes for the acceptance evidence, the known limitations, and backup and recovery; the summary is in CHANGELOG.md.
