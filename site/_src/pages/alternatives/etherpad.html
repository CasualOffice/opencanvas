An Etherpad alternative with databases and whiteboards

Etherpad is the long-standing open-source pad for writing together in real time, and the shared document many Jitsi Meet deployments use. OpenCanvas can take the same place in a Jitsi meeting and adds structured blocks, task databases, spreadsheets and a whiteboard to the notes.

The short answer

Both are open source under Apache-2.0 and both are self-hosted. Etherpad is a light, proven plain-text pad with a deep plugin ecosystem. OpenCanvas is a heavier, newer block editor for notes that also need tables, tasks, diagrams or a spreadsheet, and that should be saved into the application your people already use.

Where OpenCanvas fits better

  • More than text. Headings, checklists, callouts, tables, databases with board and calendar views, a spreadsheet block, charts and a whiteboard, all in the same live document.
  • Drop-in for Jitsi Meet. One Prosody plugin and a few .env lines, with no Docker image or compose changes. Everyone opens the same canvas from Shared document, as they would a pad. It starts blank or from a template, and is deleted when the meeting ends.
  • Saved where your files are. In Nextcloud, Mattermost channels or your own application, the canvas is a file in the host's storage, with the host's permissions and versions. OpenCanvas keeps no documents.
  • Roles enforced by the server. View, comment or edit, checked on every change; in Jitsi, moderators edit and guests get the role you configure.

Where Etherpad is stronger

  • Maturity and footprint. Etherpad has been in production for well over a decade and runs comfortably on very small servers. OpenCanvas is an early release with best-effort support and no production SLA.
  • Authorship and history. Etherpad colours text by author and has a time slider that replays a pad. OpenCanvas shows who is editing live, but its version history depends on the host, and temporary Jitsi canvases keep none.
  • Plugins. Etherpad has a large catalogue of community plugins. OpenCanvas has a Block SDK, but few third-party blocks exist yet.
  • Standalone pads. Etherpad stores pads itself and is useful with no other system. OpenCanvas always needs a host to keep the file, or uses temporary canvases.

Questions people ask.

More in the documentation FAQ.

Can OpenCanvas replace Etherpad in Jitsi Meet?{{icon:chevron-down}}

Yes. The OpenCanvas Prosody plugin uses the shared-document slot Etherpad uses, so the Shared document button opens a canvas instead of a pad. You add the plugin and a few lines of configuration; the Jitsi images stay as they are. See the Jitsi Meet guide.

What happens to the notes when the meeting ends?{{icon:chevron-down}}

In Jitsi Meet the canvas is temporary: it is deleted when the meeting ends, so people export it first (PDF, Word, Markdown or the native file). In Nextcloud Talk and Mattermost channels, meeting canvases can be saved as files in the host instead.

Can I import my existing pads?{{icon:chevron-down}}

Export a pad from Etherpad as HTML or plain text, and import the HTML when the host turns import on. Formatting carries over as far as HTML allows; author colours and pad history do not.

Is it free?{{icon:chevron-down}}

Yes. Like Etherpad, OpenCanvas is open source under the Apache-2.0 licence. Support is best effort, with no production SLA.
