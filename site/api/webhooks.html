Webhooks

OpenCanvas POSTs a file's change events to one URL of yours, so you can react without holding a stream open: index a saved file, notify on a comment. Deliveries are signed, retried, and survive restarts.

Turn them on

Webhooks are off unless the host's entry has a [host.webhooks] table:

[host.webhooks]
url          = "https://host.example.com/opencanvas/hooks"  # must be on your callback_base origin
events       = ["saved", "commented", "mentioned"]          # or ["*"]; the event types below
# secret     = "env:OC_WEBHOOK_SECRET"                      # default: callback_secret, else jwt_secret
# max_attempts = 12                                         # 1-20
SettingMeaning
urlWhere to POST. It must be on the same origin (scheme, host and port) as your callback_base; anything else stops the server at start-up and is refused again before every delivery. To receive on another domain, relay from your callback origin.
eventsThe event types to send, or ["*"] for all.
secretThe signing secret. Default: the host's callback secret, else its jwt_secret.
max_attemptsAttempts before an event is dropped, 1 to 20 (default 12, about a day).

Webhooks need a database (SQLite, MySQL or MariaDB): with Redis-only storage the server refuses to start with [host.webhooks].

The request

One POST per event. The body is the event, the same JSON as on the events stream: ids, user ids, versions and counts, never document text.

HeaderMeaning
X-OpenCanvas-EventThe event type.
X-OpenCanvas-Event-IdThe event id (ev_<ulid>).
Idempotency-KeyThe event id again: deduplicate on it.
X-OpenCanvas-Delivery-Attempt1 for the first attempt, then 2, 3, ...
X-OpenCanvas-Signaturet=<unix seconds>,v1=<hex>,v2=<hex>. Verify v2.

No bearer token is sent; the signature is the credential.

Verify the signature

v2 is HMAC-SHA256 of "<t>.POST.<path?query>.<body>" with your secret, in lower-case hex:

  1. Read the raw body bytes before any JSON parsing; a re-serialised body does not match.
  2. Use the path and query as your server received them (behind a proxy that rewrites paths, the path OpenCanvas sent to).
  3. Compare in constant time, and reject a t more than 5 minutes from your clock. t is the time of the attempt, so each retry has a new signature.

v1 (timestamp and body only) is kept for old callback verifiers; do not use it for webhooks.

Verify a delivery
# A sketch of the check: compare the hex in constant time in real code.
secret='whsec_test_example'
signature='t=1795550974,v1=4c430dee70e32585ea42f8f640c4f9197fd3f8d781cbaca4294566f61d08f656,v2=d85e216af3489979b6aaadd7c54574683679cfa8e0dee639e3d229db0e650f57'
path_query='/opencanvas/hooks'
body='{"at":1795550974787,"data":{"added":1,"blockId":"b_01m87jv4rtkdxymn93jwtx35sk","by":["u_42"],"threadId":"t_01m87jv4sqj5z6jz5q2n5zdtdw"},"fileId":"doc_1","id":"ev_01m87jv4t3ggvh8n6d6nh38xc0","type":"commented"}'

t=$(printf '%s' "$signature" | tr ',' '\n' | sed -n 's/^t=//p')
v2=$(printf '%s' "$signature" | tr ',' '\n' | sed -n 's/^v2=//p')
expected=$(printf '%s.POST.%s.%s' "$t" "$path_query" "$body" \
  | openssl dgst -sha256 -hmac "$secret" -hex | sed 's/^.*= //')
[ "$expected" = "$v2" ] && echo "signature ok" || echo "signature WRONG"
# Then reject it if t is more than 300 seconds from now:
# [ $(( $(date +%s) - t )) -le 300 ] && [ $(( t - $(date +%s) )) -le 300 ]

import hashlib
import hmac
import time


def verify_webhook(secret: bytes, signature: str, path_query: str, body: bytes,
                   now=None, tolerance=300) -> bool:
    parts = {}
    for item in signature.split(","):
        k, _, v = item.strip().partition("=")
        parts.setdefault(k, v)
    try:
        t = int(parts["t"])
        v2 = parts["v2"]
    except (KeyError, ValueError):
        return False
    if abs((time.time() if now is None else now) - t) > tolerance:
        return False
    mac = hmac.new(secret, f"{t}.POST.{path_query}.".encode() + body, hashlib.sha256).hexdigest()
    return hmac.compare_digest(mac, v2)

Answer and retries

Answer any 2xx quickly (10-second timeout) and do the work afterwards.

Your answerWhat OpenCanvas does
2xxDelivered.
Network error, timeout, 408, 425, 429, 5xxRetried after 10 s, 30 s, 1 min, 5 min, 15 min, 30 min, 1 h, 2 h, 4 h, 8 h, then every 12 h, until max_attempts; then dropped. A longer Retry-After (seconds, up to 12 h) wins.
Any other 3xx or 4xxDropped at once. Redirects are never followed.
  • At least once. An event can arrive twice: deduplicate on Idempotency-Key.
  • Order is not guaranteed across retries: order a file's events by at and the id (a ULID).
  • Durable. Events are written to a database outbox (webhook_outbox) by the server that runs the file's live room before they are sent, so they survive restarts, and exactly one server of a cluster sends each. An event can be lost only if that server dies between the change and the outbox write.

Metrics

oc_webhook_deliveries_total{host,result} (ok, retry, rejected, gave_up, refused) and oc_webhook_delivery_seconds{host} (one attempt's time), on the operations dashboard's "Webhooks" row.
