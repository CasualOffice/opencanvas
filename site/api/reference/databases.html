Databases

Describe databases, query rows with filters and sorts, create databases and fields, and create or update rows.

  • GET /api/v1/files/{fileId}/databases
  • POST /api/v1/files/{fileId}/databases
  • GET /api/v1/files/{fileId}/databases/{dbId}
  • GET /api/v1/files/{fileId}/databases/{dbId}/rows
  • POST /api/v1/files/{fileId}/databases/{dbId}/rows:upsert
  • POST /api/v1/files/{fileId}/databases/{dbId}/fields
