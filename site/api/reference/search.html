Search

Search across the canvases a person can open, through the host's own index, and extract a canvas's search text.

Search across canvases through the host (ADR-065); OpenCanvas keeps no index

  • POST /api/v1/extract
  • GET /api/v1/search

Extract search.json

POST/api/v1/extract

The search.json of a .ocanvas (or Markdown) body: the same plain-text projection every save carries, for hosts that cannot open the zip or want to re-index old files. Stateless: nothing is stored. Up to 100 MB and 2 s; comments only with [host.search] comments = true. Changes nothing, so it takes no Idempotency-Key.

Credentials
Host key, or a user token with canvas:read.
Least role
view on the file (effective permission min(scope, role)).
Operation id
extract

Request body

Required, application/vnd.opencanvas+zip.

The file itself, as the raw body.

Example

<.ocanvas bytes>

Responses

200OK: search.json

Headers

HeaderDescription
RateLimit-PolicyToken buckets that apply: "subject";q=<burst>;w=<seconds to refill>, and "file-writes" on writes
RateLimitThe bucket closest to empty: "<name>";r=<remaining>;t=<seconds until full>

import { readFile } from "node:fs/promises";
import { OpenCanvas } from "@opencanvas/client";

const oc = new OpenCanvas({
  baseUrl: "https://canvas.example.com",

});

const result = await oc.extract({ body: await readFile("notes.md") });
console.log(result);
use opencanvas_client::{Auth, CallOptions, Client, Params};

let oc = Client::builder("https://canvas.example.com")
    .auth(Auth::host_key("acme", std::env::var("OC_API_KEY").expect("OC_API_KEY")))
    .build();

let res = oc
    .call(
        "extract",
        &Params::new()
            .binary(std::fs::read("notes.md").expect("notes.md")),
        &CallOptions::default(),
    )
    .await?;
let answer: serde_json::Value = res.value()?;
println!("{answer:#}");

Search across canvases

GET/api/v1/search

Searches the canvases the token's user can open, through the host's own GET /search callback (the host indexes search.json; OpenCanvas keeps no index and caches nothing). Needs a user token: a host key gets 400 USER_TOKEN_REQUIRED. Hits on files the host's /access refuses are dropped. At most 10 searches a minute per user. The MCP tool canvas_search answers the same items.

Credentials
Host key, or a user token with canvas:read.
Least role
view on the file (effective permission min(scope, role)).
Operation id
search

Parameters

NameInTypeDescription
qrequiredquerystringThe words to look for (at most 200 bytes) At most 200 characters.
scopequerystringA scope id the host offered
cursorquerystringnext of the previous page
limitqueryintegerItems per page, 1-50 (default 20) 1 to 50.

Responses

200OK: Results

Headers

HeaderDescription
RateLimit-PolicyToken buckets that apply: "subject";q=<burst>;w=<seconds to refill>, and "file-writes" on writes
RateLimitThe bucket closest to empty: "<name>";r=<remaining>;t=<seconds until full>

Body application/json

FieldTypeDescription
itemsrequiredarray of objectAt most 50 items.
fileIdrequiredstring-
titlerequiredstring-

blockIdstring-
