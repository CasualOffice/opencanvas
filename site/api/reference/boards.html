Boards

Read a board's shapes and add shapes to a board.

  • POST /api/v1/files/{fileId}/boards
  • GET /api/v1/files/{fileId}/boards/{boardId}/shapes
  • POST /api/v1/files/{fileId}/boards/{boardId}/shapes

Create a board block with shapes

POST/api/v1/files/{fileId}/boards

A new board block after afterBlockId (default: the end) with the given shapes; shapes without coordinates are laid out (grid, flow or cluster). Answers the new boardId and blockId.

Credentials
Host key, or a user token with canvas:write.
Least role
edit on the file (effective permission min(scope, role)).
Idempotent
Send an Idempotency-Key to retry safely.
Operation id
createBoard

Parameters

NameInTypeDescription
fileIdrequiredpathstringThe host's file id 1 to 1024 characters.
Idempotency-Keyheaderstring1-255 visible ASCII characters, scoped to the caller. A repeat of the same request within 24 h answers the stored result (Idempotency-Replayed: true); another request with the same key is 422 IDEMPOTENCY_KEY_REUSED; a duplicate while the first runs is 409 IDEMPOTENCY_IN_PROGRESS. Failed requests are not stored. 1 to 255 characters.

Request body

Required, application/json.

FieldTypeDescription
shapesrequiredarray of object[{ref?, kind: sticky|rect|ellipse|diamond|text|arrow, text?, tone?, x?, y?, from?, to?}]
afterBlockIdstring-
layoutstringOne of grid, flow, cluster.

Example

{
  "afterBlockId": "blk_01m87jv4q9zr3t6y8u1i2o3p4a",
  "shapes": [
    {
      "ref": "a",
      "kind": "sticky",
      "text": "Idea"
    },
    {
      "ref": "b",
      "kind": "rect",
      "text": "Plan"
    },
    {
      "kind": "arrow",
      "from": "a",
      "to": "b"
    }
  ],
  "layout": "flow"
}

RateLimit-PolicyToken buckets that apply: "subject";q=<burst>;w=<seconds to refill>, and "file-writes" on writes
RateLimitThe bucket closest to empty: "<name>";r=<remaining>;t=<seconds until full>

import { OpenCanvas } from "@opencanvas/client";

const oc = new OpenCanvas({
  baseUrl: "https://canvas.example.com",
  auth: { hostId: "acme", key: process.env.OC_API_KEY! },
});

const result = await oc.createBoard({
  fileId: "doc_1",
  body: {
      afterBlockId: "blk_01m87jv4q9zr3t6y8u1i2o3p4a",
      shapes: [
        { ref: "a", kind: "sticky", text: "Idea" },
        { ref: "b", kind: "rect", text: "Plan" },
        { kind: "arrow", from: "a", to: "b" },
      ],
      layout: "flow",
    },
});
console.log(result);

Read a board's shapes

GET/api/v1/files/{fileId}/boards/{boardId}/shapes

The shapes of a board block in drawing order: kind, text, position and size, tone, and for arrows the shapes they connect.

Credentials
Host key, or a user token with canvas:read.
Least role
view on the file (effective permission min(scope, role)).
Operation id
readBoard

Parameters

NameInTypeDescription
fileIdrequiredpathstringThe host's file id 1 to 1024 characters.
boardIdrequiredpathstringBoard id

Responses

200OK

Headers

HeaderDescription
RateLimit-PolicyToken buckets that apply: "subject";q=<burst>;w=<seconds to refill>, and "file-writes" on writes
RateLimitThe bucket closest to empty: "<name>";r=<remaining>;t=<seconds until full>

Add shapes to a board

POST/api/v1/files/{fileId}/boards/{boardId}/shapes

Add shapes to a board: sticky, rect, ellipse, diamond, text and arrow (from and to name other shapes by their ref in the same call, or by id). Shapes without x and y are laid out (grid, flow or cluster) below what the board already holds. shapeIds maps your refs to the new ids.

Credentials
Host key, or a user token with canvas:write.
Least role
edit on the file (effective permission min(scope, role)).
Idempotent
Send an Idempotency-Key to retry safely.
Operation id
addShapes

Parameters

NameInTypeDescription
fileIdrequiredpathstringThe host's file id 1 to 1024 characters.
boardIdrequiredpathstringBoard id
Idempotency-Keyheaderstring1-255 visible ASCII characters, scoped to the caller. A repeat of the same request within 24 h answers the stored result (Idempotency-Replayed: true); another request with the same key is 422 IDEMPOTENCY_KEY_REUSED; a duplicate while the first runs is 409 IDEMPOTENCY_IN_PROGRESS. Failed requests are not stored. 1 to 255 characters.
