Comments

List comment threads, start a thread on a block or reply to one.

  • GET /api/v1/files/{fileId}/comments
  • POST /api/v1/files/{fileId}/comments

List comment threads

GET/api/v1/files/{fileId}/comments

Comment threads with their messages: the block (or quote) each is on, whether it is resolved, and who wrote each message (user id and name, never an e-mail address). resolved=false keeps the open ones.

Credentials
Host key, or a user token with canvas:read.
Least role
view on the file (effective permission min(scope, role)).
Operation id
listComments

Parameters

NameInTypeDescription
fileIdrequiredpathstringThe host's file id 1 to 1024 characters.
resolvedquerybooleanOnly resolved (true) or open (false) threads

Responses

200OK

Headers

HeaderDescription
RateLimit-PolicyToken buckets that apply: "subject";q=<burst>;w=<seconds to refill>, and "file-writes" on writes
RateLimitThe bucket closest to empty: "<name>";r=<remaining>;t=<seconds until full>

Request
curl -s "https://canvas.example.com/api/v1/files/doc_1/comments?resolved=false" \
  -H "X-OpenCanvas-Host: acme" \
  -H "X-OpenCanvas-Key: $OC_API_KEY"
import { OpenCanvas } from "@opencanvas/client";

const oc = new OpenCanvas({
  baseUrl: "https://canvas.example.com",
  auth: { hostId: "acme", key: process.env.OC_API_KEY! },
});

const result = await oc.listComments({ fileId: "doc_1", query: { resolved: false } });
console.log(result);
use opencanvas_client::{Auth, CallOptions, Client, Params};

let oc = Client::builder("https://canvas.example.com")
    .auth(Auth::host_key("acme", std::env::var("OC_API_KEY").expect("OC_API_KEY")))
    .build();

let res = oc
    .call(
        "listComments",
        &Params::file("doc_1")
            .query("resolved", false),
        &CallOptions::default(),
    )
    .await?;
let answer: serde_json::Value = res.value()?;
println!("{answer:#}");

Start a thread on a block or reply to one

POST/api/v1/files/{fileId}/comments

Start a thread on a block (blockId, optionally with the quote it is about) or on a quote alone, or reply to a thread with threadId. Needs canvas:comment. Mentions in the text notify people as in the editor.

Credentials
Host key, or a user token with canvas:comment.
Least role
comment on the file (effective permission min(scope, role)).
Idempotent
Send an Idempotency-Key to retry safely.
Operation id
addComment

Parameters

NameInTypeDescription
fileIdrequiredpathstringThe host's file id 1 to 1024 characters.
Idempotency-Keyheaderstring1-255 visible ASCII characters, scoped to the caller. A repeat of the same request within 24 h answers the stored result (Idempotency-Replayed: true); another request with the same key is 422 IDEMPOTENCY_KEY_REUSED; a duplicate while the first runs is 409 IDEMPOTENCY_IN_PROGRESS. Failed requests are not stored. 1 to 255 characters.

Request body

Required, application/json.

FieldTypeDescription
textrequiredstring-
blockIdstring-
quotestring-
threadIdstring-

Example

{
  "text": "Is Friday still right?",
  "blockId": "b_01m87jv4rtkdxymn93jwtx35sk"
}

RateLimitThe bucket closest to empty: "<name>";r=<remaining>;t=<seconds until full>

Errors

StatusCodeWhen
400IDEMPOTENCY_KEY_INVALIDThe Idempotency-Key header is empty, longer than 255 bytes, or has characters outside visible ASCII.
422IDEMPOTENCY_KEY_REUSEDThe key was used in the last 24 hours with another method, path or body. Use a new key for a new request.
409IDEMPOTENCY_IN_PROGRESSA request with the same key is still running, on this or another node. Retry after Retry-After (1 second) to get its answer.
413BODY_TOO_LARGEThe request body is over the server's limit (at least 5 MiB, the import limit).
400BAD_INPUTThe request is not what the operation takes: the body is not a JSON object, a field is missing or has the wrong type, an op, mode, format or event type is unknown, or fileId is longer than 1,024 bytes. detail says which.
404BLOCK_NOT_FOUNDNo block in the canvas has that blockId (the path's, an op's blockId, or a comment's blockId).
404NOT_FOUNDAn unknown database, board or comment thread id, or a path that is no API operation.
502HOST_UNAVAILABLEYour load or save callback failed or timed out, so the file could not be loaded or saved.
