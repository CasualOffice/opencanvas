Events and sync

Stream a file's change events, and get a ticket to sync the CRDT document directly.

Change events (SSE or WebSocket) and the headless CRDT sync ticket (HAPI-05)

  • GET /api/v1/files/{fileId}/events
  • POST /api/v1/files/{fileId}/sync-token

Change events of one file, as Server-Sent Events or (with a WebSocket upgrade) JSON text messages

GET/api/v1/files/{fileId}/events

SSE: id: <event id>, event: <type>, data: <Event JSON>, a keep-alive comment every 15 s. WebSocket: one Event per text message. Resume with Last-Event-ID (or since): the events after it from this server's in-memory ring (512 per file), or one resync event when it is gone. A stream that falls 256 events behind is closed with code 4008 (SSE: a final close event {code, reason}); a user token's stream closes with 4001 when the token expires, and with 4003 when the host revokes the user. Events carry ids only, never content.

Credentials
Host key, or a user token with canvas:read.
Least role
view on the file (effective permission min(scope, role)).
Operation id
streamEvents

Parameters

sincequerystringSame as Last-Event-ID (the header wins) At most 64 characters.

curl -s -N "https://canvas.example.com/api/v1/files/doc_1/events?types=saved,commented" \

import { OpenCanvas } from "@opencanvas/client";

const oc = new OpenCanvas({
  baseUrl: "https://canvas.example.com",
  auth: { hostId: "acme", key: process.env.OC_API_KEY! },
});

for await (const event of oc.events({ fileId: "doc_1", types: ["saved", "commented"] })) {
  console.log(event.id, event.type, event.data);
}
use opencanvas_client::{Auth, Client, EventsOptions};

let oc = Client::builder("https://canvas.example.com")
    .auth(Auth::host_key("acme", std::env::var("OC_API_KEY").expect("OC_API_KEY")))
    .build();

let mut opts = EventsOptions::new("doc_1");
opts.types = vec!["saved".into(), "commented".into()];
let mut stream = oc.events(opts);
while let Some(event) = stream.next().await {
    let event = event?;
    println!("{} {} {:?}", event.id, event.type_, event.data);
}
import json
import os

import requests

r = requests.get(
    "https://canvas.example.com/api/v1/files/doc_1/events",
    headers={
    "X-OpenCanvas-Host": "acme",
    "X-OpenCanvas-Key": os.environ["OC_API_KEY"],
    "Accept": "text/event-stream",
  },
    params={"types": "saved,commented"},
    stream=True,
    timeout=(10, 60),
)
r.raise_for_status()
for line in r.iter_lines(decode_unicode=True):
    if line.startswith("data:"):
        event = json.loads(line[5:])
        print(event["id"], event["type"], event["data"])

A ticket for the room WebSocket, so a Yjs-native client syncs the CRDT directly

POST/api/v1/files/{fileId}/sync-token

Answers a session ticket with the caller's effective role (min(scope, host role)). Connect to url (y-websocket protocol) within 60 s; the session ends at expiresAt. Takes no Idempotency-Key: the answer is a credential and is never stored. Cache-Control: no-store.

Credentials
Host key, or a user token with canvas:read.
Least role
view on the file (effective permission min(scope, role)).
Operation id
createSyncToken

Parameters

NameInTypeDescription
fileIdrequiredpathstringThe host's file id 1 to 1024 characters.

Responses

200OK

Headers

RateLimitThe bucket closest to empty: "<name>";r=<remaining>;t=<seconds until full>

const oc = new OpenCanvas({
  baseUrl: "https://canvas.example.com",
  auth: { hostId: "acme", key: process.env.OC_API_KEY! },
});

const result = await oc.createSyncToken({ fileId: "doc_1" });
console.log(result);
use opencanvas_client::{Auth, CallOptions, Client, Params};

let oc = Client::builder("https://canvas.example.com")
    .auth(Auth::host_key("acme", std::env::var("OC_API_KEY").expect("OC_API_KEY")))
    .build();

let res = oc
    .call(
        "createSyncToken",
        &Params::file("doc_1"),
        &CallOptions::default(),
    )
    .await?;
let answer: serde_json::Value = res.value()?;
println!("{answer:#}");

r.raise_for_status()
