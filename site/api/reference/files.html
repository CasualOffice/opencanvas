Export and import

Export a canvas, import Markdown, HTML or CSV into it, and convert files without a canvas.

  • GET /api/v1/files/{fileId}/export/{format}
  • POST /api/v1/files/{fileId}/import
  • POST /api/v1/convert

Export the canvas

GET/api/v1/files/{fileId}/export/{format}

The canvas as a file: md, html, json (the document JSON), ocanvas (the native file), docx or pdf. The host's export_formats decides which are allowed. Images in DOCX and PDF come only from your callback_base or asset_origins; PDF needs the operator's Gotenberg sidecar. Answers Cache-Control: no-store.

Credentials
Host key, or a user token with canvas:read.
Least role
view on the file (effective permission min(scope, role)).
Operation id
exportFile

Parameters

formatrequiredpathstringmd, html, json, ocanvas, docx or pdf One of md, html, json, ocanvas, docx, pdf.

Responses

Import Markdown, HTML or CSV into the canvas

POST/api/v1/files/{fileId}/import

Add a file's content to the canvas, after blockId or at the end, as one change. Send the file as the raw body (UTF-8, at most 5 MiB). Markdown and HTML become blocks (HTML keeps only safe links and images, never scripts or styles); CSV becomes one database block (the first column is the title; the others are typed number, date, checkbox, select or text, or by types), at most 10,000 rows and 200 columns. The format must be in the host's [host.flags] import_formats. The import path also takes diagrams (format=drawio or excalidraw, with dryRun, page and boardId) as described in the integration guide. If nobody had the file open, the answer carries the saved version.

Credentials
Host key, or a user token with canvas:write.
Least role
edit on the file (effective permission min(scope, role)).
Idempotent
Send an Idempotency-Key to retry safely.
Operation id
importFile

Parameters

NameInTypeDescription
fileIdrequiredpathstringThe host's file id 1 to 1024 characters.
formatquerystringmd, html or csv One of md, html, csv.
blockIdquerystringInsert after this block
namequerystringCSV: database name
typesquerystringCSV: JSON array of column types
Idempotency-Keyheaderstring1-255 visible ASCII characters, scoped to the caller. A repeat of the same request within 24 h answers the stored result (Idempotency-Replayed: true); another request with the same key is 422 IDEMPOTENCY_KEY_REUSED; a duplicate while the first runs is 409 IDEMPOTENCY_IN_PROGRESS. Failed requests are not stored. 1 to 255 characters.

Request body

Required, application/octet-stream.

The file itself, as the raw body.

Stateless conversion

Convert a file without a canvas: from Markdown, HTML or .ocanvas, to ocanvas, md, html, json, docx or pdf. Send the file as the raw body; the answer is the converted file. Changes nothing, so it takes no Idempotency-Key. Images in DOCX and PDF come only from your callback_base or asset_origins; boards become pictures.

import { writeFile } from "node:fs/promises";
import { readFile } from "node:fs/promises";
import { OpenCanvas } from "@opencanvas/client";

const oc = new OpenCanvas({
  baseUrl: "https://canvas.example.com",
  auth: { hostId: "acme", key: process.env.OC_API_KEY! },
});

const bytes = await oc.convert({
  query: { from: "html", to: "md" },
  body: await readFile("page.html"),
});
await writeFile("canvas.md", bytes);
use opencanvas_client::{Auth, CallOptions, Client, Params};

let oc = Client::builder("https://canvas.example.com")
    .auth(Auth::host_key("acme", std::env::var("OC_API_KEY").expect("OC_API_KEY")))
    .build();

let res = oc
    .call(
        "convert",
        &Params::new()
            .query("from", "html")
            .query("to", "md")
            .binary(std::fs::read("page.html").expect("page.html")),
        &CallOptions::default(),
    )
    .await?;
std::fs::write("canvas.md", &res.body).expect("written");

import requests

r = requests.post(
