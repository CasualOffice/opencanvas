Export and import

Export a canvas, import Markdown, HTML or CSV into it, and convert files without a canvas.

  • GET /api/v1/files/{fileId}/export/{format}
  • POST /api/v1/files/{fileId}/import
  • POST /api/v1/convert

Export the canvas

GET/api/v1/files/{fileId}/export/{format}

Credentials
Host key, or a user token with canvas:read.
Least role
view on the file (effective permission min(scope, role)).
Operation id
exportFile

Parameters

import { writeFile } from "node:fs/promises";
import { OpenCanvas } from "@opencanvas/client";

const oc = new OpenCanvas({
  baseUrl: "https://canvas.example.com",
  auth: { hostId: "acme", key: process.env.OC_API_KEY! },
});

const bytes = await oc.exportFile({ fileId: "doc_1", format: "md" });
await writeFile("canvas.md", bytes);
use opencanvas_client::{Auth, CallOptions, Client, Params};

let oc = Client::builder("https://canvas.example.com")
    .auth(Auth::host_key("acme", std::env::var("OC_API_KEY").expect("OC_API_KEY")))
    .build();

let res = oc
    .call(
        "exportFile",
        &Params::file("doc_1")
            .path("format", "md"),
        &CallOptions::default(),
    )
    .await?;
std::fs::write("canvas.md", &res.body).expect("written");
import os

import requests

r = requests.get(
    "https://canvas.example.com/api/v1/files/doc_1/export/md",
    headers={"X-OpenCanvas-Host": "acme", "X-OpenCanvas-Key": os.environ["OC_API_KEY"]},
    timeout=30,
)
r.raise_for_status()
with open("canvas.md", "wb") as f:
    f.write(r.content)

Import Markdown, HTML or CSV into the canvas

POST/api/v1/files/{fileId}/import

Credentials
Host key, or a user token with canvas:write.
Least role
edit on the file (effective permission min(scope, role)).
Idempotent
Send an Idempotency-Key to retry safely.
Operation id
importFile

Parameters

NameInTypeDescription
fileIdrequiredpathstringThe host's file id 1 to 1024 characters.
formatquerystringmd, html or csv One of md, html, csv.
blockIdquerystringInsert after this block
namequerystringCSV: database name
typesquerystringCSV: JSON array of column types
Idempotency-Keyheaderstring1-255 visible ASCII characters, scoped to the caller. A repeat of the same request within 24 h answers the stored result (Idempotency-Replayed: true); another request with the same key is 422 IDEMPOTENCY_KEY_REUSED; a duplicate while the first runs is 409 IDEMPOTENCY_IN_PROGRESS. Failed requests are not stored. 1 to 255 characters.

Request body

Required, application/octet-stream.

The file itself, as the raw body.

Example

string

Responses

200OK

Headers

HeaderDescription
Idempotency-Replayedtrue when this is the stored answer of an earlier request with the same Idempotency-Key
RateLimit-PolicyToken buckets that apply: "subject";q=<burst>;w=<seconds to refill>, and "file-writes" on writes
RateLimitThe bucket closest to empty: "<name>";r=<remaining>;t=<seconds until full>
