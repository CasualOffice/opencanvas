0.1 routes (deprecated)

The 0.1 host routes, kept through 0.x with their old answers, and retired in v0.3. Use the /api/v1 successor each one names.

  • POST /v1/files/{fileId}/patch
  • POST /v1/files/{fileId}/commit
  • POST /v1/files/{fileId}/role
  • DELETE /v1/files/{fileId}/session
  • POST /v1/files/{fileId}/members/invalidate
  • POST /v1/files/{fileId}/import
  • POST /v1/convert
