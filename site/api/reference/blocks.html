Blocks

List, read and find blocks, and change them in one atomic batch.

  • GET /api/v1/files/{fileId}/blocks
  • GET /api/v1/files/{fileId}/blocks/{blockId}
  • GET /api/v1/files/{fileId}/blocks:find
  • POST /api/v1/files/{fileId}/blocks:batch

Change blocks in one atomic transaction

POST/api/v1/files/{fileId}/blocks:batch

Ops apply in one Yjs transaction or not at all. A block op with ifMatch whose block changed answers 412 with the fresh block. Deleting more than 5 blocks needs confirm: true (409 CONFIRMATION_REQUIRED otherwise).

Credentials
Host key, or a user token with canvas:write.
Least role
edit on the file (effective permission min(scope, role)).
Idempotent
Send an Idempotency-Key to retry safely.
Operation id
batchBlocks

Parameters

NameInTypeDescription
fileIdrequiredpathstringThe host's file id 1 to 1024 characters.
If-MatchheaderstringThe document rev (ETag) the batch expects; a mismatch answers 412 STALE_BLOCK.
Idempotency-Keyheaderstring1-255 visible ASCII characters, scoped to the caller. A repeat of the same request within 24 h answers the stored result (Idempotency-Replayed: true); another request with the same key is 422 IDEMPOTENCY_KEY_REUSED; a duplicate while the first runs is 409 IDEMPOTENCY_IN_PROGRESS. Failed requests are not stored. 1 to 255 characters.

Request body

Required, application/json.

FieldTypeDescription
opsrequiredarray of BatchOpAt least 1 item.
oprequiredstringOne of append, insertAfter, replace, delete, editText.
blockIdstring-
ifMatchstringThe block rev this op expects
markdownstring-
blocksarray of object-
textEditsarray of object-
findstring-
replacestring-
modestringOne of direct, suggest.
confirmboolean-

import { OpenCanvas } from "@opencanvas/client";

const oc = new OpenCanvas({
  baseUrl: "https://canvas.example.com",
  auth: { hostId: "acme", key: process.env.OC_API_KEY! },
});

const result = await oc.batchBlocks({ fileId: "doc_1", body: { ops: [{ op: "append" }] } });
console.log(result);
use opencanvas_client::{Auth, CallOptions, Client, Params};
use serde_json::json;

let oc = Client::builder("https://canvas.example.com")
    .auth(Auth::host_key("acme", std::env::var("OC_API_KEY").expect("OC_API_KEY")))
    .build();

let res = oc
    .call(
        "batchBlocks",
        &Params::file("doc_1")
            .json(json!({"ops": [{"op": "append"}]})),
        &CallOptions::default(),
    )
    .await?;
let answer: serde_json::Value = res.value()?;
println!("{answer:#}");
