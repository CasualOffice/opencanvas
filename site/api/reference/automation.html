Automation

Rules stored in a canvas and run by the server on behalf of their owner: list, save, switch on or off, test and read the run history.

Rules in a canvas, run by the server on behalf of their owner (ADR-067); off unless [host.automation]

  • GET /api/v1/files/{fileId}/automations
  • POST /api/v1/files/{fileId}/automations:test
  • GET /api/v1/files/{fileId}/automations/runs
  • PUT /api/v1/files/{fileId}/automations/{ruleId}
  • DELETE /api/v1/files/{fileId}/automations/{ruleId}
  • POST /api/v1/files/{fileId}/automations/{ruleId}/enable

List automation rules

GET/api/v1/files/{fileId}/automations

The rules stored in the canvas (the automations root), each with whether it can run and, for date and schedule rules, nextRunAt (ms), plus the host's limits and the origins URL calls may reach. Anyone who can read the file can read its rules.

Credentials
Host key, or a user token with canvas:read.
Least role
view on the file (effective permission min(scope, role)).

Test run a rule

POST/api/v1/files/{fileId}/automations:test

What a rule (saved or not) would do on the most recent matching row, or rowId: the trigger, each condition and each action's effect. Changes nothing and sends nothing; costs no run.

Credentials
Host key, or a user token with canvas:write.
Least role
edit on the file (effective permission min(scope, role)).
Idempotent
Send an Idempotency-Key to retry safely.
Operation id
testAutomation

Parameters

NameInTypeDescription
fileIdrequiredpathstringThe host's file id 1 to 1024 characters.
Idempotency-Keyheaderstring1-255 visible ASCII characters, scoped to the caller. A repeat of the same request within 24 h answers the stored result (Idempotency-Replayed: true); another request with the same key is 422 IDEMPOTENCY_KEY_REUSED; a duplicate while the first runs is 409 IDEMPOTENCY_IN_PROGRESS. Failed requests are not stored. 1 to 255 characters.
