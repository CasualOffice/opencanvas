Admin

Host operations: save now, change a user's role live, close the session, drop cached members.

  • POST /api/v1/files/{fileId}/commit
  • POST /api/v1/files/{fileId}/role
  • DELETE /api/v1/files/{fileId}/session
  • POST /api/v1/files/{fileId}/members:invalidate

Save now (200 saved, 202 queued in the outbox, 409 conflict)

POST/api/v1/files/{fileId}/commit

Save the canvas to your application now, for example before you back it up. 200 once your save callback answered (saved: false when there was nothing new), 202 when the save failed and waits in the outbox to be retried, 409 when your callback reported a conflict.

Credentials
Host key, or a user token with canvas:admin when the host sets [host.api] token_admin.
Idempotent
Send an Idempotency-Key to retry safely.
Operation id
commitFile

Parameters

NameInTypeDescription
fileIdrequiredpathstringThe host's file id 1 to 1024 characters.
Idempotency-Keyheaderstring1-255 visible ASCII characters, scoped to the caller. A repeat of the same request within 24 h answers the stored result (Idempotency-Replayed: true); another request with the same key is 422 IDEMPOTENCY_KEY_REUSED; a duplicate while the first runs is 409 IDEMPOTENCY_IN_PROGRESS. Failed requests are not stored. 1 to 255 characters.

200OK

Idempotency-Replayedtrue when this is the stored answer of an earlier request with the same Idempotency-Key
RateLimit-PolicyToken buckets that apply: "subject";q=<burst>;w=<seconds to refill>, and "file-writes" on writes
RateLimitThe bucket closest to empty: "<name>";r=<remaining>;t=<seconds until full>

Change a user's role live (none disconnects them)

POST/api/v1/files/{fileId}/role

Change a user's role on the file, live: their open sessions switch at once (view makes them read-only, none disconnects them and drops them from the member list). The role also applies to launch tokens issued before the call. Answers how many live connections switched and sessions were updated.

Credentials
Host key, or a user token with canvas:admin when the host sets [host.api] token_admin.
Idempotent
Send an Idempotency-Key to retry safely.

Failed requests are not stored. 1 to 255 characters.

The member list changed; drop cached answers

POST/api/v1/files/{fileId}/members:invalidate

Tell OpenCanvas the file's member list changed outside a role call: the cached members answer is dropped and open editors fetch it again.

Credentials
Host key, or a user token with canvas:admin when the host sets [host.api] token_admin.
Idempotent
Send an Idempotency-Key to retry safely.
Operation id
invalidateMembers

Parameters

NameInTypeDescription
fileIdrequiredpathstringThe host's file id 1 to 1024 characters.
Idempotency-Keyheaderstring1-255 visible ASCII characters, scoped to the caller. A repeat of the same request within 24 h answers the stored result (Idempotency-Replayed: true); another request with the same key is 422 IDEMPOTENCY_KEY_REUSED; a duplicate while the first runs is 409 IDEMPOTENCY_IN_PROGRESS. Failed requests are not stored. 1 to 255 characters.

Responses

200OK

HeaderDescription
Idempotency-Replayedtrue when this is the stored answer of an earlier request with the same Idempotency-Key
RateLimit-PolicyToken buckets that apply: "subject";q=<burst>;w=<seconds to refill>, and "file-writes" on writes
RateLimitThe bucket closest to empty: "<name>";r=<remaining>;t=<seconds until full>
