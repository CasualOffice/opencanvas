Read a canvas as JSON blocks, Markdown or an outline

GET/api/v1/files/{fileId}

The canvas as JSON blocks (default), Markdown or a heading outline. Every block carries its blockId and a rev hash; the document rev comes back as ETag. Pass a block's rev as ifMatch, or the document's as If-Match, when you change it.

If nobody has the file open, OpenCanvas loads it from your load callback first.

Credentials
Host key, or a user token with canvas:read.
Least role
view on the file (effective permission min(scope, role)).
Operation id
readFile

Parameters

NameInTypeDescription
fileIdrequiredpathstringThe host's file id 1 to 1024 characters.
formatquerystringjson (default), markdown or outline One of json, markdown, outline.

Responses

200OK

Headers

HeaderDescription
ETagThe document (or block) revision, quoted.
Idempotency-Replayedtrue when this is the stored answer of an earlier request with the same Idempotency-Key
RateLimit-PolicyToken buckets that apply: "subject";q=<burst>;w=<seconds to refill>, and "file-writes" on writes
RateLimitThe bucket closest to empty: "<name>";r=<remaining>;t=<seconds until full>
Link<…?cursor=…&limit=…>; rel="next" when more follow

Errors

StatusCodeWhen
400BAD_INPUTThe request is not what the operation takes: the body is not a JSON object, a field is missing or has the wrong type, an op, mode, format or event type is unknown, or fileId is longer than 1,024 bytes. detail says which.
502HOST_UNAVAILABLEYour load or save callback failed or timed out, so the file could not be loaded or saved.

Also, like every operation on a file: API_OFF, UNAUTHENTICATED, TOKEN_INVALID, TOKEN_EXPIRED, SCOPE_REQUIRED, ROLE_FORBIDDEN, FILES_REQUIRED, RATE_LIMITED, UNAVAILABLE, INTERNAL.

Request
curl -s "https://canvas.example.com/api/v1/files/doc_1?format=json" \
  -H "X-OpenCanvas-Host: acme" \
  -H "X-OpenCanvas-Key: $OC_API_KEY"
import { OpenCanvas } from "@opencanvas/client";

const oc = new OpenCanvas({
  baseUrl: "https://canvas.example.com",
  auth: { hostId: "acme", key: process.env.OC_API_KEY! },
});

const result = await oc.readFile({ fileId: "doc_1", query: { format: "json" } });
console.log(result);
use opencanvas_client::{Auth, CallOptions, Client, Params};

let oc = Client::builder("https://canvas.example.com")
    .auth(Auth::host_key("acme", std::env::var("OC_API_KEY").expect("OC_API_KEY")))
    .build();

let res = oc
    .call(
        "readFile",
        &Params::file("doc_1")
            .query("format", "json"),
        &CallOptions::default(),
    )
    .await?;
let answer: serde_json::Value = res.value()?;
println!("{answer:#}");
import os

import requests

r = requests.get(
    "https://canvas.example.com/api/v1/files/doc_1",
    headers={"X-OpenCanvas-Host": "acme", "X-OpenCanvas-Key": os.environ["OC_API_KEY"]},
    params={"format": "json"},
    timeout=30,
)
r.raise_for_status()
print(r.json())
