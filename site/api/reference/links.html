Links

The canvases that link to a canvas, as a person may see them, and the host's maintenance of the link index.

Links between canvases and backlinks (ADR-081); the index holds ids only and every answer goes through the host's ACL

  • GET /api/v1/files/{fileId}/backlinks
  • DELETE /api/v1/links/files/{fileId}
  • POST /api/v1/links/index
  • GET /api/v1/graph

Canvases that link to this canvas

GET/api/v1/files/{fileId}/backlinks

"Linked from" (ADR-081): the canvases whose last acknowledged save links to this canvas (or, with block, to one block of it), newest save first, 20 to a page. Needs a user token: a host key gets 400 USER_TOKEN_REQUIRED. The token's user needs view on this canvas, and every linking canvas is checked with the host (POST /access/batch, else POST /access): one the user cannot open is left out and not counted, in items, total and blocks alike. Titles and paths are the host's answers; excerpts are made from the linking canvas at read time and never stored. Needs [host.flags] links. The MCP tool canvas_backlinks answers the same.

Credentials
Host key, or a user token with canvas:read.
Least role
view on the file (effective permission min(scope, role)).
Operation id
listBacklinks

Drop a deleted file's links from the index

Backfill the link index from your files

POST/api/v1/links/index

Loads each file through your load callback (with the host key's callback bearer), writes its outgoing links to the index and drops the document; nothing else is kept. Up to 100 files per call; run it once over your files when you turn [host.flags] links on. Files that are missing, fail to load or are not .ocanvas are listed in failed with not_found, host_error or not_ocanvas. Host key only.

The link graph between canvases

GET/api/v1/graph

The knowledge graph (ADR-082) from the link index. With root: the canvases around it, breadth-first in both directions to depth. Without: the most-connected canvases of your application, up to limit. Every canvas is checked with your /access/batch (else /access) before it is shown or expanded, so a canvas the user cannot open is neither a node nor a bridge between two others. truncated says the walk stopped early; total is given only when every candidate was checked. in and out count the edges in this answer. Needs a user token and [host.flags] links; 10 graphs a minute per person, 2 of them full. Cached 30 s per person and parameters. The MCP tool canvas_graph answers the same.

Credentials
Host key, or a user token with canvas:read.
Least role
view on the file (effective permission min(scope, role)).
Operation id
getGraph

Parameters

NameInTypeDescription
rootquerystringA file id for a local graph; absent for the full graph 1 to 1024 characters.
depthqueryinteger1-3 around root (default 1) 1 to 3.
